Azure: Kysymyksiä ja vastauksia

1. Mikä on Microsoft Azure ja mihin sitä käytetään?

2. Mitä eroa on Azure Virtual Machinella ja Azure App Servicellä?

3. Mikä on Azure Resource Group?

4. Mihin Azure Blob Storagea käytetään?

5. Mikä on Microsoft Entra ID:n rooli Azuressa?

Vastaukset

1. Microsoftin pilvipalvelualusta, jolla voi ajaa sovelluksia, palvelimia, tietokantoja ja muita IT-palveluita.

2. VM antaa kokonaisen virtuaalipalvelimen hallittavaksi, kun taas App Service on valmiimpi alusta web-sovellusten ajamiseen.

3. Looginen ryhmä, johon Azure-resurssit, kuten VM:t ja tietokannat, voidaan koota hallintaa varten.

4. Käytetään suurten tiedostojen ja objektidatan, kuten kuvien, videoiden, varmuuskopioiden ja dokumenttien tallentamiseen.

5. Hallitsee käyttäjien tunnistautumista, kirjautumista ja käyttöoikeuksia Azure-palveluihin.
